# Web Frames map demo
A working static web app, without dependencies. From this directory run:

    python3 -m http.server 4318 --bind 127.0.0.1

Choose this folder in Web Frames → Project map & inventory. Set Running site to http://127.0.0.1:4318 and add the three pages. Components are real JavaScript DOM factories; the inventory shows static file references, not runtime coverage.
